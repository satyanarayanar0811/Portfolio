Agentic AI · Healthcare imaging · LiveMedica

LUECI HP — Hanging Protocol Agent

Real-timein-viewer decisioning

Problem

Radiologists lose time manually arranging CR and Mammography image layouts for every study — the "hanging protocol" — inside the viewer.

Approach

Built an in-viewer AI agent that reads DICOM context, runs vector search over imaging-template embeddings, and calls tool-style actions to apply the correct protocol automatically.

Result

Protocol selection happens inline during the study, removing a manual step from every read across two modalities.

Document infrastructure · Concentric Consulting

Document Management System

OCR +full-text search

Problem

Scanned and unstructured documents weren't searchable, and there was no access control or audit trail.

Approach

Ran Elasticsearch via Docker, used pytesseract to OCR scanned documents into text, then indexed that text in Elasticsearch for full-text search with role-based access control and audit logging.

Result

Documents became findable by content, not just filename, with a traceable access history.
